# Sukhoi Studio

A fanmade website dedicated to the history, technology, and evolution of Sukhoi's legendary fighter aircraft, from the iconic Su-27 Flanker to the fifth-generation Su-57 Felon.

## Features

- Responsive design optimized for desktop and mobile devices
- Customizable theme (light/dark)
- AOS (Animate On Scroll) for smooth page transitions
- Built-in dark mode toggle
- Support for dark mode on browsers that support it
- Support for dark mode on iOS and Android devices
